# TeamCraft 1.0.0


TeamCraft 1.0.0 is the first stable release of TeamCraft, a Fabric mod for quickly creating and managing multiplayer teams through a graphical interface or commands.

### Highlights

- Split players by maximum team size or a fixed number of teams.
- Assign players in list order or randomly.
- Customize team names, color rotation, and friendly-fire settings.
- Manage your own team or browse and manage all TeamCraft teams.
- Invite online players to existing teams with 120-second invitation expiry.
- Configure command access with five permission levels, from `all` to `owners`.
- Persist team configuration and permission settings with each world.
- Open the interface through configurable hotkeys or Mod Menu.
- Use the complete `/teamcraft` command system when a GUI is not desired.
- Available in American English, British English, Simplified Chinese, Hong Kong Traditional Chinese, and Taiwan Traditional Chinese.

### Requirements

- Fabric Loader 0.19.5 or newer
- The Fabric API version matching your Minecraft version
- Java 21 or newer for Minecraft 1.21–1.21.11
- Java 25 or newer for Minecraft 26.1.2–26.3
- Mod Menu is optional but recommended

> [!IMPORTANT]
> For multiplayer, TeamCraft must be installed on the server and every client. Download the JAR that matches your Minecraft version.
